# 단위 과제곡 메이커 · NIJIIRO 2026

브라우저 안에서 과제곡 카드를 편집하고 투명 PNG로 저장하는 정적 웹 앱입니다.

- 2026 단위도장 5급~달인 57곡 프리셋
- 제목·아티스트·단위 명패, 쉬움/보통/어려움/오니/우라 레벨 1~99
- 상단 과제곡 우라와 하단 오니/우라 독립 선택
- 비트맵 글꼴과 16방향 텍스트 테두리
- 투명 PNG, 1~4배 출력, 회전·가로 변형, 전곡 ZIP 저장
- 브라우저 내 프리셋 보관 및 Windows 버전과 호환되는 설정 JSON
- 모바일 대응. 입력한 정보와 생성 이미지는 서버에 전송하지 않습니다.

## 실행

Node.js에서 `npm start`를 실행한 뒤 표시되는 localhost 주소를 엽니다. 의존성 설치나 빌드 과정은 없습니다. `file://`로 직접 여는 대신 HTTP 서버를 사용하세요.

## GitHub Pages

`main` 브랜치의 루트(`/`)를 게시 대상으로 지정합니다. 파일은 상대경로를 사용하므로 프로젝트 Pages 경로에서 실행됩니다. `.nojekyll`이 포함되어 있습니다.

## 개발

- `renderer.js`: Canvas 렌더러와 설정 검증
- `app.js`: 편집기, 검색, 브라우저 저장, PNG/ZIP 내보내기
- `zip.js`: UTF-8 이름을 지원하는 무압축 ZIP 작성기(PNG는 자체 압축)
- `presets.json`: 57곡 프리셋
- `assets/`: 이미지와 글꼴

`npm run check`로 JavaScript 문법을 확인합니다.
